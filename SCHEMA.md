# Схема статьи (контракт)

Каждая статья — это один `.md` файл в папке `articles/`. Файл состоит из двух частей: **frontmatter** (метаданные между `---`) и **тело** (сам текст в Markdown).

## Frontmatter

```yaml
---
title: "Заголовок статьи (H1)"
slug: "url-statyi-translitom"
seo_title: "SEO-заголовок до 60 символов"
seo_description: "Мета-описание до 160 символов, попадает в RankMath."
focus_keyword: "главный ключ"
category: "Овощи и зелень"
tags:
  - тля
  - вредители
status: draft
images:
  - https://mir-doma.pro/wp-content/uploads/2026/07/tlya-1.jpg
---
```

| Поле | Обязательное | Что делает |
|------|--------------|------------|
| `title` | да | Заголовок поста (H1). Без него файл пропускается. |
| `slug` | нет | URL статьи. Если нет — строится из title. |
| `seo_title` | желательно | Title для RankMath. Лимит — 60 символов. |
| `seo_description` | желательно | Description для RankMath. Лимит — 160 символов. |
| `focus_keyword` | нет | Фокусный ключ RankMath. |
| `category` | да | Должна совпадать с существующей категорией сайта. |
| `tags` | нет | Список меток. |
| `status` | нет | `draft` или `publish`. Переопределяет настройку плагина. |
| `images` | нет | Зарезервировано. Пока картинки вставляются прямо в тело. |

## Тело

Обычный Markdown. Поддерживается:

- `## Заголовок` → H2, `### Подзаголовок` → H3
- списки (маркированные и нумерованные)
- **жирный**, *курсив*, [ссылки](https://mir-doma.pro)
- таблицы
- картинки: `![alt-текст](https://...jpg)` — alt берётся в alt-тег
- цитаты `>` и блоки кода

Плагин превращает это в нативные блоки Gutenberg, так что в редакторе статья откроется обычными блоками, а не «Классикой».

## Партнёрские ссылки

Партнёрская ссылка пишется в теле статьи через схему `aff:`:

```markdown
[Аккумуляторные триммеры в каталоге](aff:vi-trimmery-akkum)
```

`vi-trimmery-akkum` — ключ из справочника `affiliate/links.yml` в корне
этого репозитория:

```yaml
vi-trimmery-akkum:
  network: admitad            # admitad | vseinstrumenti | yandex-market | ozon
  advertiser: "ООО «ВсеИнструменты.ру»"
  url: ""                     # пусто, пока ссылка не выдана
  erid: ""
  note: "Каталог аккумуляторных триммеров"
```

Ключ заводит тот, кто пишет статью, — сразу с пустыми `url`/`erid`, но с
заполненными `advertiser` и `note`. Формат ключа: `<магазин>-<категория>`,
латиница и дефисы.

Плагин раскрывает `aff:<ключ>` в обычную ссылку **при выводе на сайте**, а
не при импорте статьи — значит после того, как владелец получит `url` и
`erid` и впишет их в `links.yml`, ссылки заработают во всех уже
опубликованных статьях без переимпорта. До этого момента:

- ключа нет в справочнике, или `url` пустой → на сайте виден только текст
  ссылки, без `<a>` — битых ссылок и `aff:` в HTML не бывает;
- `url` заполнен, а `erid` пустой → ссылка тоже не активируется (без erid
  показывать рекламную ссылку нельзя) — только текст, а факт записывается
  в лог плагина;
- `url` и `erid` заполнены → обычная ссылка с
  `rel="sponsored nofollow noopener"`, и после блока, где есть хотя бы одна
  такая ссылка, выводится маркировка мелким шрифтом вида «Реклама.
  {advertiser}. erid: {erid}».
