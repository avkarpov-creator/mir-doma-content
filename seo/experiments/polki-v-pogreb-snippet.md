# Эксперимент: сниппет под «стеллаж для банок» + калькулятор

**Статья:** polki-v-pogreb-svoimi-rukami
**Дата правки:** 2026-09-29
**Гипотеза:** реальные запросы в Вебмастере (срезы 13.09 и 20.09) —
«стеллаж в подвал для банок», «полки в погребе для хранения банок»,
«стеллаж для банок в погреб». В старом title нет ни «банок», ни
«стеллажа», поэтому при позиции 5–10 сниппет не совпадает с запросом.
Если добавить в title/description эти слова и калькулятор веса полки,
CTR должен вырасти.

## Замер ДО
- GSC web, окно 22.09–29.09: показов 18, позиция 5,5, кликов 0.
- Яндекс, окно 13.09–20.09 (до сезонного спада): ~40 показов по кластеру
  «полки/стеллаж в погреб», позиции 6,5–12,5, 1 клик.

## Что изменено
- seo_title: «Полки в погреб своими руками: материалы и расчёт нагрузки» →
  «Полки и стеллаж для банок в погреб своими руками»
- seo_description: банки, стеллаж, «чтобы не сгнил», калькулятор.
- В раздел «Расчёт нагрузки на полку» добавлен калькулятор: длина полки,
  доска, тип банок → банок в ряд, вес, число стоек. Нормы пролёта и вес
  банки взяты из текста статьи.

## Замер ПОСЛЕ
Яндекс — срез 06.10, Google — 13.10. Сезон погребов идёт на подъём
(закладка урожая), поэтому сравнивать CTR, а не показы.

### Промежуточно, срез 04.10 (окно 28.09–04.10, пересекается с правкой)
- GSC web: показов 24, позиция 5,6, кликов 1, CTR 4,2% (было 0 из 18).
- Яндекс: 1 показ по «полки для погреба своими руками» (поз. 26). Замер
  непригоден из-за сезонного спада.
Окно захватывает день правки, а Google обновляет сниппет с лагом. Выводов
