подсчёта.

**Глубина просмотра продолжает падать**: 1,65 (16.08) → 1,13 (23.08) → 1,31
(30.08). Тренд просел ещё до штрафного порога 1,3 из `weekly-brief.md`, а не

по тексту. Отказы колеблются 8,7–14,8% без чёткого тренда, не диагностично.

**Индексация в Яндексе растёт**: 99 страниц на 16.08 → 135 на 30.08 — это
точка на дату сбора, а не окно, поэтому сравнение соседних и любых строк
прямое. Исключённых 1–2 страницы, не тревожно. `sqi` держится на нуле весь
период — стоит свериться в Вебмастере, это ещё не считается или реальный
ноль.

**GSC: показы и клики web выросли к середине периода и просели к концу.**
Показы web: 414 (16.08) → пик 630 (26.08) → 505 (30.08). Клики web: 2 (16.08)
→ пик 15 (25.08) → 11 (30.08). Похоже на локальный откат после пика, не на
устойчивое падение — рано делать выводы, но стоит посмотреть следующий срез.
Показы image (505 web / 465 image в последнем окне) не подтверждают правило
«90% показов картиночные» из `seo.md` для этого сайта конкретно: доля картинок
колеблется 48–65%, не 90%. Возможно, это общее наблюдение с других проектов —
не трогаю `seo.md`, это не входит в задачу, но стоит иметь в виду при следующих
разборах.

## 2. Стоп-лист

Кандидат слабый по объёму, но чистый по критерию: **«потолок на холодной
веранде»** — позиция 1,0 (GSC, web), 3 показа, 0 кликов. Позиция топ-3 без
кликов — сигнал, что интент перехватывает сниппет/выжимка, а не что странице
чего-то не хватает. Тему не брать, но и не бить тревогу — выборка в 3 показа
слишком мала, чтобы это был устойчивый паттерн, а не случайность недели.

По Яндекс.Вебмастеру кандидатов нет: ни один запрос с позицией ≤3 не набрал
достаточно показов (весь диапазон 1–2), делать вывод не на чем.

## 3. Что усилить

**Главная находка недели**: страница `otdelka-holodnoy-verandy` — 173 показа
за неделю (web), позиция 5,1 — совсем рядом с топом, но **CTR 0,6% (1 клик)**.
Это ровно кейс из `seo.md`: «показы без кликов у страницы = сниппет не
отвечает на запрос». Позиция достаточно хороша, чтобы не быть причиной низкого
CTR — проверить и переписать `seo_title`/`seo_description`, дать реальное
обещание пользы, а не общее описание раздела.

Второй кандидат — сам запрос **«отделка холодной веранды внутри»** (пул
запросов страницы): позиция 7,0, 21 показ, 0 кликов. Дописать в
`otdelka-holodnoy-verandy` раздел, отвечающий буквально на эту формулировку
(сейчас страница явно ранжируется по теме, но не хватает пары позиций до
топа) — дешевле, чем спутник, и без риска повторить прецедент с «Чем обшить
веранду внутри».

Более тонкие кандидаты (5–20 позиция, но показы 2–4 — на грани значимости):
«чем отделать стены в холодной веранде» (5,0), «отделка стен холодной
веранды» (9,0), «материалы для отделки холодной веранды» (16,5). Стоит
держать в уме при следующей правке той же статьи, отдельного действия не
заслуживают — слишком тонкая выборка недели.

## 4. Работающие интенты

**«Обои для холодной веранды» — CTR 27,3% с позиции 1,7** (запрос) и CTR 10,6%
на уровне страницы `oboi-na-holodnoy-verande` — образцовый пример «можно ли /
чем» интента с понятным материальным ответом. Формулировка для поиска похожих
тем в других кластерах: конкретный материал + конкретное холодное/открытое
помещение («обои для X», «чем X для холодной веранды» и т.п.).

Из Яндекс.Вебмастера, с осторожностью (выборка 2–3 показа, не доказательство,
а подсказка направления): формулировки с явным «своими руками, пошагово» и
«какой материал использовать» получают клики чаще при том же объёме
показов — это совпадает с высокой кликабельностью «как сделать пошагово»
из `priorities.md`.
