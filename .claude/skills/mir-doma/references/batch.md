# Пакетный выпуск статей

Триггер: «давай N статей» / «сделай три статьи».

## Отбор тем

```bash
python3 scripts/mdi.py index
python3 scripts/mutagen.py pick "<опорная фраза>" --min-freq=10 --max-strong=8
```

Опорные фразы брать из тонких рубрик (`mdi.py state`) и доказанных кластеров
в пропорции 2:1 — две темы в сильный кластер, одна в тонкую рубрику.
Если по фразе всё в дублях, кластер выработан: бери следующую фразу.

**Порядок отбора среди прошедших порог:**

1. Отбросить региональные запросы («в минске», «нижний новгород», названия
   городов). Локальную выдачу мы не выигрываем, а читатель из другого города
   на такой странице бесполезен.
2. Отбросить диагностический интент — его забирают AI-выжимка и карусель.
3. Из оставшихся выбрать по кликабельности интента: сравнение материалов,
   расчёт стоимости, пошаговый монтаж, «можно ли / нужно ли».
4. **Частотность — только тай-брейкер.** При двух равных по интенту темах
   берётся та, что чаще. Сама по себе высокая частотность не аргумент:
   кластер огурцов держал топ-3 при высокой частотности и давал ноль кликов,
   а «обои для холодной веранды» с частотностью в единицы дали CTR 27,3%.
5. Проверить сезонное окно: статья выходит в топ за 1–3 месяца, значит тема
   пишется за 1–3 месяца до пика спроса.

**Показать мне список тем и дождаться подтверждения.** Для каждой темы одной
строкой: слаг, рубрика, конкуренция, частотность, чем интент отличается от
существующих статей. Это дешёвая точка контроля — переписывать потом дороже.

## Выпуск каждой статьи

Последовательно, не параллельно. Для каждой:

1. `mdi.py dupe "<тема>"` — при РИСК ДУБЛЯ сформулировать дифференциатор
   одной фразой или снять тему
2. `mdi.py linkplan <слаг> "<Рубрика>" "<тема>"`
3. `mdi.py new`, написать текст по `article-contract.md`
4. 3–5 ссылок в теле + входящие в 2–4 донора, у доноров `adopt_existing: true`
5. `images.py init`, заполнить промпты по-английски
6. **Показать промпты и дождаться ok.** Шесть кадров стоят около $0,40,
   три статьи — больше доллара. Минута чтения дешевле неудачной генерации.
7. `./scripts/ship.sh <слаг>`

Между статьями — короткий отчёт: слаг, объём, входящие ссылки, стоимость.
Текст статей в чат не выводить никогда.

## Взаимное пересечение внутри пакета

Три статьи пишутся в один заход, и `mdi.py dupe` не видит те, что ещё не
написаны. Перед началом сверить темы между собой вручную: если две из трёх
отвечают на близкий интент, вторую заменить. Каннибализация внутри пакета —
самый вероятный способ испортить эту работу.

## Что докладывать в конце

Список слагов, суммарная стоимость картинок, что осталось на мою сторону
(импорт в WordPress и публикация). Автопубликации нет намеренно.
