# Источники данных и порядок деградации

Два разных вопроса, и они закрываются разными сервисами:

| Вопрос | Кто отвечает | Замена |
|---|---|---|
| Есть ли спрос (частотность, похожие фразы) | Wordstat | Букварикс, Мутаген |
| **Пробьёмся ли в топ (конкуренция 1-25)** | **только Мутаген** | **замены нет** |

Отсюда главное правило: **если Мутаген молчит, конвейер не переключается на
другой источник, а останавливается перед решением о теме.** Wordstat и Букварикс
дают собрать поле кандидатов и отсеять мусор, но выбрать из них тему без данных
о конкуренции — ставка вслепую.

## Порядок при сборе тем

1. `wordstat.py tails "<фраза>"` — свежие частотности первоисточника
2. Если Wordstat недоступен: `bukvarix.py tails "<фраза>"` — цифры устаревшие,
   годятся как ориентир
3. Если недоступны оба: `mutagen.py tails` (требует подписки с доступом по API)
4. **По выжившим обязательно** `mutagen.py strong "<фраза>"`
5. Нет ответа от Мутагена → темы записать в `semantics/SEMANTIC-CORE.md`
   со статусом `ждёт проверки конкуренции` и остановиться. Не писать статью.

Единственное исключение: тема подтверждена данными Search Console — например,
позиция в выдаче уже есть, а страницы нет. Тогда конкуренция уже доказана
фактом ранжирования, Мутаген не нужен. Так была выпущена
`chem-obshit-naves-iznutri`.

## Wordstat

Официальный API Яндекса в составе Yandex Cloud Search API. На момент настройки
вызовы Вордстата бесплатны, но сервис в бете — статус стоит сверять на странице
тарифов AI Studio.

```bash
python3 scripts/wordstat.py check                     # доступ
python3 scripts/wordstat.py top "утепление веранды"   # похожие + частотность
python3 scripts/wordstat.py freq "фраза1" "фраза2"    # частотность списка
python3 scripts/wordstat.py tails "фраза" --min=10    # с фильтрами проекта
```

Ответ содержит два блока: `results` — фразы, содержащие ключ, и `associations` —
что ещё искали по теме. Второй блок часто ценнее: он выводит на смежные
формулировки, до которых по основному ключу не добраться.

Регион по умолчанию 225 (вся Россия). Москва — 213, полный справочник через
метод getRegionsTree.

Настройка: Yandex Cloud → каталог → сервисный аккаунт с ролью
`search-api.webSearch.user` → API-ключ с областью `yc.search-api.execute`.
Ключ в `.yandex.token`, идентификатор каталога в `.yandex.folder`, оба в
`.gitignore`.

## Букварикс

Аварийный вариант. Частотности обновляются реже вордстатовских, конкуренции нет.
Бесплатный ключ `free` с ограничением строк в ответе.

```bash
python3 scripts/bukvarix.py check
python3 scripts/bukvarix.py tails "фраза" --min=10
```

## Общие фильтры

Все три скрипта используют один интент-фильтр из `mutagen.py`, чтобы правила
не разъезжались. Отсеиваются автоматически: диагностика и фото-интент,
региональные запросы (города, «область», «в районе»), дубли по индексу статей.

Что отсеивается — видно в строке «отсеяно» с разбивкой по причинам. Если
кандидатов вышло ноль, сначала смотри туда, а не меняй пороги вслепую.
