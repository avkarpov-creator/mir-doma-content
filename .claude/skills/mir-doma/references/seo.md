# Разбор SEO-выгрузок

## Цикл

```bash
# 1. Сложить выгрузки в seo/inbox/ (csv, xlsx, zip — как выгрузилось)
# 2. Собрать индекс, иначе сверка со статьями не сработает
python3 scripts/mdi.py index
# 3. Сводка
python3 scripts/seo.py digest
# 4. Claude Code пишет бриф по сводке
# 5. Убрать разобранное
python3 scripts/seo.py archive
```

Отдельные срезы: `seo.py files`, `queries`, `pages`.

## Закон

**Сырой CSV в контекст не грузится.** Тысячи строк выгрузки — это десятки тысяч
токенов ради данных, из которых нужны три вывода. `seo.py` читает файлы с диска
и печатает сводку строк на пятьдесят.

## Что показывает сводка и что с этим делать

**Топ-3 и ноль кликов.** Позиции 1–3, показы есть, кликов нет. Запрос забирают
AI-выжимка и карусель картинок. Такие темы не брать — проверено на кластере
болезней огурцов: топ-3 и почти ноль трафика.

**Близко к топу, позиции 5–20.** Показы есть, до топа не хватает. Дешевле дописать
разделы в существующую статью, чем писать спутник. Спутник рядом с пиллером
уже ронял пиллар с 6,5 на 12,1.

**Высокий CTR.** Работающий интент. Образец для новых тем: если запрос вида
«чем обшить X внутри» даёт 9,8% с восьмой позиции, ищи такие же формулировки
в других кластерах.

**Показы без кликов у страницы.** Либо сниппет не отвечает на запрос, либо
интент нерабочий. Первое чинится переписыванием `seo_description`, второе — нет.

**Сверка с репозиторием.** Статьи без единого показа скорее всего не в индексе —
проверяй входящие ссылки через `mdi.py in <слаг>`. Слаги из выдачи, которых нет
ни в репозитории, ни в `external-slugs.txt`, созданы вручную в WordPress —
добавь их в список, иначе `mdi.py check` будет считать ссылки на них битыми.

## Обязательное условие для GSC

**Выгружай веб и картинки отдельно.** Доля картиночных показов не константа —
по срезу на 30.08 она 48–65% в зависимости от раздела, неделей раньше или
позже число будет другим. Пересчитывай долю по каждой новой выгрузке, а не
полагайся на прошлое число. Требование раздельной выгрузки при этом не
меняется: в смешанном виде сегменты искажают позиции и CTR друг друга
независимо от того, какая доля показов у картинок в конкретную неделю.
Скрипт различает сегменты по имени файла: `web`/`веб` и `image`/`картин`
в названии. Переименуй файлы при выгрузке, иначе оба сегмента сольются в один.

**Проверяй полноту.** Экспорт, обрезанный на 50 или 1000 строк, даёт ложную
картину: скрипт предупредит, если страниц в выгрузке вдвое меньше, чем статей
в репозитории, и откажется делать вывод о непроиндексированных.

## Формат файлов

Понимает csv, tsv, xlsx, zip (GSC отдаёт архивом). Мусорные строки перед шапкой —
как у GA4 — пропускает. Колонки ищет по русским и английским названиям, десятичную
запятую и неразрывные пробелы разбирает.

Если файл не распознался, `seo.py files` покажет, какие колонки нашлись.
Незнакомое название колонки добавляется в словарь `COLS` в начале скрипта.

## Где лежит

`seo/inbox/` — приёмник, `seo/archive/<дата>/` — разобранное.
Обе папки в `.gitignore`: это данные сервисов, в репозитории контента им не место.
