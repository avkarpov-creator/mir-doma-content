# Картинки: генерация и контракт

## Контракт

`.jpg`, ровно **1200×675** (16:9), качество 86, без метаданных, вес до ~250 КБ.
Шесть кадров на статью: в `frontmatter.images` и в теле, у каждого alt.

Почему 1200×675, а не крупнее: в контенте картинка показывается шириной ~800 px,
запас на retina уже заложен. Разница между 1200×675 и 1600×900 на глаз незаметна,
а вес отличается в полтора раза.

## Генерация

```bash
python3 scripts/images.py init  <слаг>   # скелет промптов из frontmatter + alt
#   заполнить поля prompt по-английски
python3 scripts/images.py cost  <слаг>   # сколько будет стоить
python3 scripts/images.py gen   <слаг>   # только недостающие файлы
python3 scripts/images.py check <слаг>   # соответствие контракту
```

Ключ: `GEMINI_API_KEY` или `.gemini.token` в корне (в `.gitignore`).
**Подписка Gemini не даёт доступа к API** — нужен ключ из Google AI Studio.
Модель: `MD_IMAGE_MODEL`, по умолчанию `gemini-3.1-flash-image` (Nano Banana 2).

Ориентир цены, август 2026: ~$0,067 за кадр у `gemini-3.1-flash-image`,
~$0,034 у `gemini-3.1-flash-lite-image`. При 3 статьях в день по 6 кадров это
примерно $36 и $18 в месяц. Batch API даёт минус 50%, но с задержкой до суток.
Цены проверяй на ai.google.dev/pricing — они меняются.

Главная экономия не в тарифе, а в идемпотентности: существующий файл не
перегенерируется, повторный прогон статьи стоит ноль.

## Как писать промпты

Работает: конкретный предмет + материал + ракурс + время суток.
«Mineral wool slabs fitted between wooden studs of a veranda wall, close-up» — хорошо.
«Утепление веранды» — плохо, получится случайный интерьер.

Стилевая часть (фотореализм, естественный свет, без людей, без текста и водяных
знаков) приклеивается скриптом из константы `STYLE` — контракт не зависит от того,
вспомнил ли о нём автор промпта. В промпт её дописывать не надо.

Промпты пишутся по-английски: качество заметно выше, а подпись всё равно берётся из alt.

Обложка (первый кадр) — общий план объекта, остальные иллюстрируют конкретные шаги.
Не заказывай кадры с руками за работой: там, где модель рисует людей, чаще всего
появляются артефакты, а контракт людей и запрещает.

Что бы модель ни вернула, скрипт кадрирует по центру до 16:9, ресайзит в 1200×675,
сохраняет JPEG и вырезает метаданные. Проверено на квадратном, панорамном и
вертикальном исходниках.

В картинках Gemini присутствует невидимая метка SynthID. Это не видимый водяной знак,
контракту не противоречит, убрать нельзя.

Если генерация ответит 404 — названия моделей у Google меняются по нескольку раз в год.
Сверяйся с документацией, не подбирай имя наугад.

## Уже загруженные картинки

```bash
python3 scripts/optimize-images.py report      # что сейчас
python3 scripts/optimize-images.py run --dry   # что изменится
python3 scripts/optimize-images.py run         # применить
```

Приводит существующие файлы к тому же контракту. Идемпотентно, оригиналы остаются
в истории git до коммита.
