# Конвейер выпуска статьи

Семь шагов, из них пять автоматических. Останов на первой проблеме — намеренно:
чинить опубликованное дороже, чем не публиковать.

## Цикл целиком

```bash
# 1. Найти тему с порогами
python3 scripts/mutagen.py pick "<опорная фраза>" --min-freq=200 --max-strong=5

# 2. Проверить на каннибализацию и найти доноров ссылок
python3 scripts/mdi.py dupe "<тема>"
python3 scripts/mdi.py linkplan <слаг> "<Рубрика>" "<тема>"

# 3. Скелет и текст
python3 scripts/mdi.py new <слаг> "<Рубрика>"
#    написать статью в файл, расставить 3-5 ссылок в теле,
#    добавить входящие ссылки в 2-4 статьи-донора (adopt_existing: true у них!)

# 4. Промпты для картинок
python3 scripts/images.py init <слаг>
#    заполнить prompt по-английски: предмет + материал + ракурс + время суток

# 5. Всё остальное
./scripts/ship.sh <слаг>
```

## Что проверяет ship.sh

| Шаг | Проверка | Почему останавливает |
|---|---|---|
| 0 | токены вне git | утечка = чужие расходы с твоего баланса |
| 1 | индекс собран | без него проверки врут |
| 2 | структура статьи | seo-поля, картинки, alt, битые слаги |
| 2 | **входящих ссылок ≥ 2** | без входящих страница не индексируется |
| 3 | промпты заполнены | пустой промпт = кадр не сгенерируется |
| 4 | картинки по контракту | 1200×675 JPEG без метаданных |
| 5 | повторная валидация | после генерации могло что-то поехать |
| 6 | состав коммита | только файлы этой статьи |
| 7 | подтверждение пуша | последняя точка, где можно передумать |

В коммит попадают только `articles/<слаг>.md`, его картинки, `prompts/<слаг>.json`
и статьи-доноры. Посторонние незакоммиченные правки остаются вне коммита.

## После пуша — вручную

1. Админка WordPress → Настройки → Git Importer → **«Проверить GitHub сейчас»**
2. Ревью черновика: картинки на месте, ссылки ведут куда надо, таблицы не разъехались
3. Публикация

Автопубликации нет намеренно. Статья, вышедшая с битой таблицей или чужой картинкой,
стоит дороже, чем минута ревью.

## Пороги отбора темы

`--min-freq=200 --max-strong=5` — жёсткий вариант для теста конвейера.
В обычной работе конкуренция до 8 берётся сразу, 9–12 — если тема попадает
в сильный кластер. Частотность 200 отсекает много годных узких расчётных тем,
у которых при 50 запросах CTR выше, чем у диагностических с 1500.

Пороги отвечают на вопрос «пробьёмся ли», а приоритет по-прежнему определяет
формула из `priorities.md`: кликабельность × сезонное окно × вес кластера.
